# Worksheet Generator

This is a web app for generating handwriting practice worksheets. It supports custom fonts and Excel input. 

## How to deploy to GitHub Pages

1. Push this folder to your GitHub repository `worksheegenerator` under your username `nagasakimark`.
2. In your repository settings, enable GitHub Pages and set the source to the `main` branch and `/ (root)` folder.
3. Your site will be available at: https://nagasakimark.github.io/worksheegenerator/

## Files
- `index.html`: Main app
- `names.html`: Additional page
- `font.otf`, `writingfont.otf`: Custom fonts
- `TEMPLATE.xlsx`: Example Excel file

## Notes
- All assets must be in the root directory.
- No build step is required; this is a static site.
